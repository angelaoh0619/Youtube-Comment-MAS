# Prepared public example

This directory makes the completed Re.View walkthrough reproducible without uploading anyone's personal workspace.

- `four-day-week.json` is the authored walkthrough snapshot generated by `scripts/prepare_example_journey.py`.
- `sample-analysis/` is the portable, curated analysis used by `scripts/setup_example.py`. It includes the retained public source comments, perspective groups, agent bundle, display catalog, source-comment translation cache, and matching `04_web/example_journey.json`.

The source is the public SBS workweek discussion video [BAHKmi4F1L8](https://www.youtube.com/watch?v=BAHKmi4F1L8). Comment IDs and original text are preserved so evidence can be inspected. Comments are statements by their respective authors, not verified external facts or statements endorsed by this project.

The initial/current opinions and user questions are fictional demo material. Agent responses and reflection were generated from the public analysis. There are five conversations containing 54 messages. No visitor's private initial view, conversations, or reflection is included.

The portable copy replaces machine-specific metadata paths with relative paths and updates the dependent analysis fingerprints. Its agent content and fictional journey are unchanged. The installed `04_web/example_journey.json` takes precedence over the authoring snapshot, ensuring that its source fingerprint matches the installed analysis.

Only these six files are installed:

```text
01_filter/filtered.json
02_group/groups.json
03_agents/agents.json
04_web/catalog.json
04_web/translations.json
04_web/example_journey.json
```

Raw collection files, personal runtime records, model response caches, deployment credentials, and unrelated local analyses are not part of this sample. To reproduce collection and analysis from scratch, use your own API keys to collect a new source snapshot; the prepared sample is for exploring the finished result.
